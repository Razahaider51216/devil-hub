# 👿 DEVIL HUB | Anime Defenders

Auto script hub for Anime Defenders (PlaceId: 8304191830)

## Features
- Auto Farm (spawn, upgrade, active attack, wave skip, retry)
- Auto Hatch + Auto Sell
- Auto Quest (NPC, secret quest)
- Auto Dungeon (full run)
- Auto Infinite Tower + Roguelike
- Auto Claim All Rewards
- Auto Shop Buy + Travelling Merchant
- Auto Redeem Codes
- Auto Equip Best
- Anti-AFK + Auto Reconnect
- Settings Save/Load
- Status Log

## Usage

Paste in your executor:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Razahaider51216/devil-hub/main/DevilHub.lua"))()
```

## Keybinds
- `RightCtrl` — Toggle GUI visibility
- Drag top bar to move
